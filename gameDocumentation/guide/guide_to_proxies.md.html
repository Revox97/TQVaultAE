(#) Guide - Proxies It is possible to place the monster .dbr's directly in the world but generally it is done via Proxies. A proxy can dispense multiple enemies in an area of variable size, or even create an ambush. Unless configured otherwise, a proxy dispenses monsters upon being loaded (when about two screens away), based on its parameters. # Proxy (Proxy.tpl) The proxy to be placed in the world. Can have an accessory (loot chest) and selects monsters from a list of pools. ## Proxy config **difficultyEquationFile** Usually four to choose from per act. Determine the proxy’s difficulty in accordance with its size (01-03) and quality (normal/tough): * _01 - Proxy 01n * _02 - Proxy 01t / 02n * _03 - Proxy 02t / 03n * _04 - Proxy 03t **difficultyLimitsFile** Links to a ProxyLimits.tpl that is used to limit the players level. Set according to act and area number (usually 001-008 corresponding to waypoints). **chanceToRun**: The chance for this proxy to dispense upon load. 100% default. **placementExtents**: The area that this proxy will dispense monsters into, a radius around its point of origin. Increase to spread out larger camps or ambushes (e.g. rising zombies) **delayedRun**: Proxy that does not spawn until activated by a quest. ## Proxy Tables **pool#, weight# ** The monster spawn Pools(ProxyPool.tpl) this Proxy dispenses from. If more then one pool is listed it will select on of them according to their relative weights. * Usually Epic and Legendary entries are left blank, in which case normal entries will be re-used. Only exceptions are proxies that change with difficulty. * Ambush proxies are normal proxies, but link to ambush pools with invisibly starting monsters that have respective AIs. * Unified proxies are linked in the Editor as a group. They will all share the same randomized number for the pool to use. ## Accessory **accessory1 / Epic1 / Legendary1** Links to the proxys accessory pools for each difficulty. These then select and spawn chests. (-> Container Guide). FYI: A chest proxy is simply a proxy which has an accessory but zero enemies around it. ## Actor Variables Used to define the appearance of the proxy in the Editor. Set the mesh to the shape of the monster and use a fitting color texture from \Creatures. # ProxyLimits.tpl Listed as the difficultyLimitsFile in a proxy. This limit the player level to a min/max player level for further proxy calculation. The player level will snap to min or max if it is outside. The min/max is set per difficulty. # ProxyEquation.tpl Listed as the difficultyEquationFile in a proxy. Calculates a difficulty rating based on player level and player number, gradually increasing over the acts. # ProxyAccessoryPool.tpl # ProxyPool.tpl Spawn Pools are referenced by proxies. They contain the actual list of monsters to spawn and their relative weights. The distinction between regular and champion pools is purely in the name. You can spawn any monster from any pool. Often ~2% chance of heroes. ## Pool config * Spawn min/max: The number of monsters to spawn from the Pool * campionChance: Each monster spawned has this % chance to be from the Champion Pool. * Champion min/max : How many champions will show up. * ProxyPoolEquation: Record reference for modifying the spawn min/max values. The same proxypoolequation_01.dbr is used for all spawn pools. ## Pool & Champion pool There are two pools in a proxypool, the champion pool and the normal pool. The proxypool is given a amount if difficulty to spawn, it will first spawn from the champion pool if any and then from the normal pool. It will pick a creature at random based on weight and for each creature spawned it will lower the pool difficulty with the difficulty of the monster. When pool difficulty is zero it will stop spawning. * name#: The monster dbr to spawn. * weight#: The relative weight of dispensing this particular monster. * limit#: The maximum number of this monster that can spawn from any pool of this name in the nearby area. * difficulty: available when difficulty exceeds value, subtracts from available difficulty when selected * difficultycutoff: not available when difficulty exceeds value * alwaysspawn: Sets whether this monster always spawns independent of weight. Should always be coupled with a Limit (usually 1) as otherwise every monster that the pool dispenses will be this monster. # ProxyPoolEquation.tpl Modifies the monster pools min and max value of how many normal creatures and champions can spawn. Same for all acts and difficulties.
