# Shaders Shaders are found in resources\shaders\shaders.arc. The are compiled and stored in .ssh files. The path to them in game and in files is stored as shaders\standardstatic.ssh. The file name start with the type of shader and then the flags for what features it have. Each shader have some parameters that you can set in 3DS max that tweak how it will look. Some shaders exist in two versions, one of them with a t at the end of the name, ex standardstatic and standardstatict. The t stands for transparent and is used when the objects is in front of a player and it needs to turn transparenct to show the player character. The t shaders are used by the game and should not be used for things you create. # What shader to use Here are the shaders and what they are used for. Example meshes is listed to look at in the viewer. ## Standard The shader to use in almost all cases. **Static or Skinned** The first choice is to select the skinned or the static one.
