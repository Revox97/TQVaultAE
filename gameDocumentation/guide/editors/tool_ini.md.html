The configuration for the tools are stored in .ini files in MyGames/Titan Quest - Immortal Throne/Tools.ini. They are split into [sections] and then one parameter on it's own line. # Tools.ini ## [Login] **Localdir** Where the source files for the mods are. **builddir** Where the mod is put when you build it. **Toolsdir** The directory where the tools to build the game is. The install directory for your game. **Additionalbuilddirs** Extra directories to be loaded by the tools. Seperated by ; . **moddir** Name of the mod that been set as active in the artmanager. Menu mod/set as active. It is the one mod directory where the viewer try to find source files. Unused * 3dsmaxserver * Username=? * Database=? ## [SplashScreen] **Splashenable=1** **splashmute=0** ## [Build] ExportStatistics=0 ## [Database] Settings for the database editor in the artmanager. **lastMod=** The last mod that was open in the artmanager. The editor will try to show it at startup. **nameColumnWidth=100** Width of the name column in database editor. **classColumnWidth=60** Width of the class column in database editor. **typeColumnWidth=60** Width of the type column in database editor. **descriptionColumnWidth=150** Width of the description column in database editor. **valueColumnWidth=100** Width of the value column in database editor. **defaultValueColumnWidth=200** Width of the defaultValue column in database editor. **viewDescriptions=0** If set to 0 the description column will not show in database editor. ## [Editor] Note: If you have a 1920x1200 display and show the windows toolbar at the bottom to receive a 1:1 pixel mapping. * xResolution=1590 * yResolution=1031 **xResolution=1024** Set the x resolution to render things with in the editor. **yResolution=768** Set the y resolution to render things with in the editor. autoCloseArchives=0 splitterPos=1118 **lastMod=** The last mod that was open in the editor. The editor will try to show it at startup. **lastLevel=Levels\World\World01.wrl** The last level that was open in the editor. The editor will try to select it at startup. defaultMod=Art_TQX3 lastLayoutPos=-5041,0,4699 **Terrain Brushes** The brush settings for the terrain tools. * RaiseLower: RaiseLowerRadius, RaiseLowerStrenght, RaiseLowerSpeed. * Roughen: RoughenRadius, RoughenStrenght, RoughenSpeed * Smooth: SmoothRadius, SmoothStrenght, SmoothSpeed * Plateua: PlateuaRadius, PlateuaStrenght, PlateuaSpeed, PlateuaHeight * Relative: RelativeRadius, RelativeStrenght, RelativeSpeed, RelativeOffset * Ramp: RampWidth * Brush: BrushRadius, BrushStrenght, BrushSpeed, BrushOpacity * Passable: PassableRadius, PassableStrenght, PassableSpeed * WaterBrush: WaterBrushRadius, WaterBrushHeight * WaterPath: WaterPathRadius # [Configuration Data] **windowWidth** **windowHeight** **templateDirectory** # [Aif File Data] **windowWidth=-1** **windowHeight=-1** # [Options] **editInPlace** **enableGrid** # [Viewer] **xResolution=1024** Set the x resolution to render things with in the viewer. **yResolution=768** Set the y resolution to render things with in the viewer. **trippleBuffer=0** Should viewer use tripple buffer. # QuestEditor.ini This file contains options for the QuestEditor. ## [Layout] **isMaximized=0** **filesdisplay_x=?** **assetdisplay_x=?** **propertiesdisplay_y=?** **Lowerpanel_y=?** **Form_height=?** **form_width=?** ## [Asset Tabs] NumTabs=1 Tab0Name=Assets Tab0Dirs=
