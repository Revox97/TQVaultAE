# Items for the player character 1. These tools can be found via your start menu, under ‘Programs -> THQ -> Titan Quest -> Toolset’. 2. To get started, go there now and run the Art Manager. You will prompted to choose your working directories. The default values are good – just click ‘OK’. 3. The Art Manager will open and the working directories will be set up under ‘My Documents -> My Games -> Titan Quest > CustomMaps’. 4. Next, go to the Help menu and select ‘Install Tutorials’. This will copy the tutorial files that you should use while reading this guide. Everything should now be properly set up. Proceed when ready. ![The basic male player model seen in 3DSMax](guide_images/items/items01.jpg) This is the male player character model seen in 3DSMax. It is rigged and ready to go. ![Unique armor model](guide_images/items/items02.jpg) **General armor guidelines** This is one of the new Unique armor models from the Atlantis expansion. The male and female player characters need to have unique versions made to work with their respective topology. It is important to try and match the armor topology to the underlying character in most cases, it makes the skinning easier to handle. This is also true for any mosters items, as the monsters will have to use their own unique version. This results in 3 models having to me made for the respective wearers. We will only cover the one in this tutorial, as the process is the same for them all. # Skinning the armor ![](guide_images/items/items03.jpg) 1. Select the armor model 2. Click the modifier list on the right side of the screen 3. Scroll down and select the Skin Wrap modifier 4. Select Face Deformation under the Deformation Engine headline 5. Set fallof to 0.0001 and Threshold to 3.0 5. Click the Add button and then click on the player character, this will add it as the target of the skin wrap 6. Once this is loaded in, click the Convert To Skin button ![](guide_images/items/items04.jpg) This creates a new modifier called Skin, and that is what we will be editing. ![](guide_images/items/items05.jpg) The result has something to be desired though, so we will have to do some editing. It helps to pose the character in some extreme pose, just to see where the armor breaks. ![Open world box in the editor](guide_images/items/items06.jpg) With the armor and skin modifier selected, it's time to do some adjusting to the skinning. 1. Click the Edit Envelopes button under Parameters 2. Click on the vertices that need adjusting 3. Click the Weight Tool, this opens up a new window where we will do our editing to the skin weights. 4. With the desired bone selected in the Weight Tool, press the + or - buttons next to the Set Weight button in the Weight Tools window. This will adjust the weight for the selected vertices ![](guide_images/items/items07.jpg) There are times when you want to uniformly increase the skin weight of a whole seperate object included in the armor. In this case it is the skull on the waist. 1. Click the Select Element checkbox 2. Click on the desired part of the model 3. Adjust the values as before in the Weight Tool # Setting up the shader and the material ![](guide_images/items/items08.jpg) This step requires the 3DSMax plugin to be activated, this step will not be covered here. 1. Click the icon with the round shape in the toolbar, opening up the Material Editor 2. Select the desired material slot in the Material Editor 3. Click the Shader button next to the material name 4. Select the "Shader" Shader under Standard Materials (If it's not there, the plugin is not working) ![](guide_images/items/items09.jpg) With the right material we are now able to edit the shader for the selected material. The type of shader to use will depend of the specific armor you are making. Generally the StandardSkinned shader works well. In this case I am using StandardSkinnedNoCulling, as the inside of the armor has no faces, and we want to avoid holes. Basically it makes the mesh faces appear double sided. 1. Click the ... button next to the shader name 2. Select the desired shader to use # Exporting the armor ![](guide_images/items/items10.jpg) Next step is to hide the player model and export the armor. You can select the armor and then right click it and press Hide Unselected to hide the player model. With this done we are ready to export. 1. Click File and Export Selected in the 3DSMax menu 2. Browse to the desired folder 3. Name your model 4. Select Model Exporter (.MDL) from the Save as type drop down menu (If it's not there, the plugin is not working) 5. If this is the first time you save a model, make sure to include .mdl with lower case in the file name. (u_torso02_m.mdl in this case) If you don't add .mdl the first time you save the file, max will do it for you, but it will look like this: .MDL, and this causes an error when you build the model later, so make sure you set it up correctly from the start. ![](guide_images/items/items11.jpg) With the model exported it's time to set it up in the Art Manager. Browse your way to where you saved the file under the Sources tab 1. Right click the item 2. Click Auto-Create Asset ![](guide_images/items/items12.jpg) The process for making a texture will not be covered here, only how you make it work in the game. 1. Right click the item texture 2. Click Auto-Create Asset 3. Click Texture and OK ![](guide_images/items/items13.jpg) In the Texture Properties window you can setup what type of texture you need to use, if it uses alpha or not. In this case we don't use any alpha, so I use DXT1 (no alpha) as the format. ![](guide_images/items/items14.jpg) When creating the .mdl asset, make sure the Source is correct and click OK. ![](guide_images/items/items15.jpg) With the above done, it's time to build the assets we have just created. 1. Click the Asset tab and browse to the correct folder 2. Right click the item and press build (This will build just the desired item and not the whole project) # Setting up the item database ![](guide_images/items/items16.jpg) Once you have built the asset in the Art Manager, it's time to add it to the item database. The naming here will be up to you, but the default naming conventions used by TQ can be a bit confusing. This particular item's database is named U_E_02.dbr. U is for Unique and E is for Epic (it only drops in epic difficulty). Let's hook it all up and see if it works as expected. 1. Click the Database tab and browse to the right folder 2. Double Click the Datebase file 3. Select Actor Variables 4. Set up the correct path for the item model and texture we made (If you can't find them, it means you didn't build the asset. If you did and they are still gone, restart the Art Manager and try again) The Actor Varibles setup is what determines the look of the item when it first drops in the game, what you see on the ground. But it can also work as a "default" model in other cases, which will be covered below. ![](guide_images/items/items17.jpg) Under the Armor Parameters tab you need to setup the model used by the Female and Male player character. This is where you set it up for the different monster types as well. What you enter here will override the armor selected in Actor Variables. So in the case of monster items, you add the monster model in Actor Variables if the monster you have doesn't belong to any of the types shown in the screenshot. And then you set up your player models like above. This gives the monster the correct armor and also the player. ![](guide_images/items/items18.jpg) Under the Item Parameters tab you select the bitmap used for this particular item. The Bitmap is what you see in the inventory screen. This can be different for the male and female character if desired. ![](guide_images/items/items20.jpg) With the above steps completed we are ready to test our item in game. Save and close the item database and build the project. (Or just the selected .dbr as described above) # Testing it out ![](guide_images/items/items21.jpg) You can setup your own custom items level for easy access.
