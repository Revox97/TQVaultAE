The pseditor in TitanQuest is fairly basic and most of the funtions are self-explantory. But here are some pointers to get you going. Picture below depicts an overall view of the editor. ![ ](guide_images/pseditor/pseditor.png) # Graph windows Regardless changing color,size or emit rate for a particle you will do it with the graph window. To add a manipulation point you rightclick on the curve and then leftclick to move it. To remove a point you rightclick on it again. ![ ](guide_images/pseditor/pseditor_graph.png) Don'ts Avoid to type in zero and negative values because then they will be corrupted and disappear, this is irreversible. ![ ](guide_images/pseditor/pseditor_graph_no.png) # Shaders When choosing the shader it is important that you using the shaders in the particle folder, otherwise they will not be displayed correctly or at all in the game. ![ ](guide_images/pseditor/pseditor_shaders.png) # Flipbook Textures Titanquest supports flipbook textures, but most of the ingame effects doesn't use this, probably because this function seems a bit sketchy. If using animated textures then Frames per second is important because this regulates the animation play speed. ![ ](guide_images/pseditor/pseditor_flipbook_fps.png) To create a flipbook texture, rightlclick on the texture under assets and take edit, then add the textures in the sequence. ![ ](guide_images/pseditor/pseditor_flipbook.png) # From Ps editor to the game When saving an effect from the pseditor you will need to specify the complete source location in the highlighted field below where you want the file to be saved, you also need to type in the file extension .pfx otherwise the file will not be saved. ![ ](guide_images/pseditor/pseditor_save.png) To create a game asset you rightclick on the pfx-file and click Auto-Create Asset. ![ ](guide_images/pseditor/create_pfx_asset.png) The next step in the implementation is to create a database with the template Effect.tpl. Here you connect your auto created pfx file, now you should be able to see the effect in the Editor. ![ ](guide_images/pseditor/pseditor_dbr_connect.png) # Database Templates Effect.tpl : Predominantly the most used template, this will do for the most effects. FxPak.tpl: This template allows you to add a camera shake to your effect and also spawn a mesh. Notice that you do not connect the pfx file directly, intead it needs it's own dbr. ![ ](guide_images/pseditor/pseditor_templates.png) # Mif To be able to connect an effect to an object or character you need to do this via a mif file. Attachpoint = Creates a locator from which your effetcs spawns. Here you can specify the location with giving X,Y,Z Axis different values. You can also changed the location of the attachment point in the mesh editor but when saving the mif data from the editor, a bug removes the CreateEntity part in the mif file. Entity = The path to your particle effect. ![ ](guide_images/pseditor/pseditor_mif.png) To be able to move the attachment points in the Model viewer first you need to Set as active under Mod in the Art Manager. Then you need to check attachments to see them. You are not able to create new points in the editor, you can only do that in the mif-file. ![ ](guide_images/pseditor/pseditor_viewer.png) # Aif To trigger an effect in an animation you need both a mif and an aif file. In the mif you create the attachement point in this example "Mudpool". In the Aif you define which attachement should be used and in which frame the effect should occur during the animation. ![ ](guide_images/pseditor/pseditor_aif.png) To attach an aif file to an animation you rightclick on the animation clip under the asset tab and connect the aif. The aif file should be located in the same folder as the animations in sources. ![ ](guide_images/pseditor/pseditor_aif_connect.png) # Additional ways to spawn a effect Besides uisng a mif/aif file to trigger an effect there are sometimes other ways to achieve this. For instance if you just want's to add a spawn or death effect for a specific creature you can do it directly in the creature dbr. ![ ](guide_images/pseditor/pseditor_spawn.png)
