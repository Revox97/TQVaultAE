# Titan Quest Blender Tool [Blender](https://www.blender.org/) is free and open source 3D creation suite. The Titan Quest Blender add-on let you use blender to modify models for use in Titan Quest. # Install guide * Start blender and open the preferences window for addon by selecting the Edit/Preferences menu and then the Add-ons tab. * Select the Install button and browse to the titan_quest_blender.zip file. You find it inside a Toolset folder of your game install folder. * Search the list for the Import-Export: Titan quest addon and make sure the box beside it is check to have it loaded. * Set the preferences of the add-on. * Working directory: Set this to the working directory where your mods are stored. It's the same one set in the artmanager. The folder contains a customap folder with the mods. The addon will try to load textures from the mod directories. * UnpackDirectory: # Import a Titan Quest .msh The models that the game use are in .msh format and import them into blender with File/Import/Titan Quest (.msh). # Materials When a .msh have been loaded it will show each material as a solid color. If it managed to load the textures you can set the viewport to Look dev mode to see them. The display in blender only display the baseTexture of a material so the final look must be inspected in the Titan Quest viewer. # Export a Titan Quest .mdl The mdl file is what is used by the ArtManager to build models for the game. So to get a model into the game you need to export to mdl, build it with the artmanager and then check it in the viewer. Use File/Import/Titan Quest (.mdl) to export it from blender. On each blender material is a Titan Quest Settings section and it is the only place to modify the settings for Titan Quest. No changes off the other blender settings for materials will have any effect when exported. * Shader: The titan quest shader to use for the material. Not many supported yet and loading a unsupported one will crash the import for now :). Each shader has it's own list of parameters. * Parameters: This is a list of the parameters of the shader. * First is the name of the parameter. * There are textures and vectors. All vectors display as 4 number right now but some of them use less. Like specularColor use 3 and specularPower 1.
