(#) Ambient Music DBR (Template: MusicPak.tpl) The Ambient Music DBR can be set up by either using drones or music tracks alone. The drone setup contains of one looping drone music track as well as several melodies and a number of percussions played on top of the drone. * randomizeMelodies lets you choose whether Melodies should play randomly. 1 (Yes) or 0 (No). * Drone is the section for the location of the drone music track (mp3). Keep it blank if not using drone. A drone is an accompaniment with one or a few continuously sounded notes and need melodies to be complete. ![XXX](images/audio_musicpak1.png) * Melody# are the actual music tracks or melodies (mp3). When drone is used this is for the locations of the melodies. The melodies plays one after another and the time between is set by Min/MaxTime. * Percussion# is short percussion tracks that plays randomly (mp3). Only used with drone. * Volume sets the volume. 1 = 100%. * Min/MaxTime … ![XXX](images/audio_musicpak2.png) (#) Ambient Sound DBR (Template: AmbientPak.tpl) * enableNightSounds lets you choose whether the ambient sounds should alternate depending on the ingame time. 1 (Yes) or 0 (No). * ambientLoop is similar to using a Drone. It’s a looping track with ambient sounds set in the background. ![XXX](images/audio_ambient_pak1.png) * frequent/moderate/uniqueSound# are short ambient sounds played randomly over the ambientLoop. ![XXX](images/audio_ambient_pak2.png) (#) Event Music DBR (Template: EventMusicPak.tpl) * eventMusicName is for the event music track.
