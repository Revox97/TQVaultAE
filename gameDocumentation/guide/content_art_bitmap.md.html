# Bitmaps 1. Under the Source tab of the Art Manager, locate the folder in which your texture file is located and click it, its contents will be shown in the window to the right. 2. Right click your texture file and choose "Auto-Create Asset". This will prompt you to choose an Asset Type. In this case, where the texture is going to be applied to a UI asset/Icon,the Asset Type should be specified as "Bitmap", press "OK" to continue. 3. You will be face with a window labeled "Asset Properties". Here you specify the source file for your bitmap. Usually this is already filled in based on the source file you're building from. 4. Press "OK". Your bitmap has now been built into an Asset that can be found under the Asset tab in the Art Manager, and be accessed from the shader menu in 3DS Max.
