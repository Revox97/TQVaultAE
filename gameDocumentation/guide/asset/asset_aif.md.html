(#) .aif - Animation Information File A aif file is used to specify some of the extra parameters and settings in a animation. # Format * The file is in text format. * A tag is in the form of Tag { param = value }. * A string value should be inside quotation marks. * A vec3 value inside (). # Tags **CallbackPoint** This creates events that are fired of when the animation reach the selected frame in the animation. For a list of supported event names look below. * *name* : Name of event to fire, it is case-sensitive. * *frame*: Frame at which the event is fired. **CreateEntity** Used to create an object at a certain frame when the animation plays. Ex create a particle effect when a creature stomps the ground. * *frame* : At wich frame in the animation to create the entity. * *entity* : Path to dabase .dbr of the entity to create. * *attach* : Seems to be (optional) name of bone (on the parent) whereas the new entity will be attached. But not entirely sure. **RagDollData** * effectType : No way to know how many different hard coded checks there are for this. But Skill::InitRagDollData checks for “TakeHit”. These has comments: * Crumple: Falls down using only the velocity of the current animation * TakeHit: Rigidbodies around the "target" get velocity specified. Others get random. * Random: All rigidbodies get some random amount of velocity. * direction ”Push|Pull” * elevation ”Upward|Downward” * push “Left|Right” # Event names for CallbackPoint Here are the possible names to use in the CallbackPoint and what they do. A name listed with a * a number range in parentheses lets exist in more then one version. So PS*Start (1-3) tells you that there is PS1Start, PS2Start and PS3Start. * End : Ends current skills active action. **Hit** Trigger the hit of weapons or the effect of skill. Get the position from the attachment point in the mesh. (“Foot” is used only in special cases, to hit unarmed while carrying a weapon.) * RightHandHit : Hit enemy / cast spell (use this unless there is a reason against) * LeftHandHit : for left hand when dual wielding, shield, bow or staff * Hit : * FootHit : * SpecialHit0* (1-4) : **Swipes** * Swipe = Make swipe sound & weapon leave a trace (~5 frames before hit). swipe sound for special hits, specified in monster dbr. Play swipe sound for weapon or arm. * SwipeRight = the right weapons own swipe sound, and weapon trail. Uually a few frames before the respective hand’s hit * SwipeLeft = for left hand when dual wielding, shield, bow or staff. the left weapon own swipe sound, and weapon trail. Uually a few frames before the respective hand’s hit * SwipeBoth = both weapon swipe sound. Enable weapon trail for left, right or both weapons. **Skills** * SkillSound* (1-2) = Play skill’s extra sound (for more than swipe & hit) * SkillProp*Add (1,2 or none) : Add a prop that will be used while performing a skill animation. * SkillProp*Hide (1,2 or none) : Hide a prop used in a skill. * SkillProp*Remove (1,2 or none) : Remove the prop used by the skill. * HideMainWeapon* (L or R) : Needed to hide main-weapon when throwing onehanded * ShowMainWeapon* (L or R) : **Particle System** * PS*Start (1-3) : When to play animation-bound skill particle effects (particleEffectName#) on certain bones. Always good to have this trigger in attack / cast / buff anims, even if not currently used. In doubt just on frame 1. * PS*End (1-3) : Stop the particle effect on the active skill. **Character** * Footstep (* is L or R) : Play a sound and place a decal on the ground. * Pickup : Only for PC pickup animation * Fall * StopRotation * lootGen : At what frame should an item container spawn its loot. **AttackAction** * TurnStart : In a AttackAction where the character turns towards the target start turn at the given frame. Used specifically for PC turn animations. * TurnEnd : End the turning towards the target. **Typhon** * BreakTheChains - Typhon script * OpenPortal - Typhon script * EnterPortal - Typhon script * ragDoll **Sounds** * voxSound : Use in attacks for a chance to make a common sound while striking. Use VoiceSound for 100% chance or SkillSound# for custom animation-triggered sounds. * genericSound* (1-4) : secondary sounds, like flapping of wings, steam from mashines, chains swinging etc * voiceSound* (1-3) : casting of spells. Play actor’s voice sound (e.g. battlecry, usually 100% chance). * specialAttackSound* (1-4) = Jaws opening, squeaks from machines. Play actor’s extra sound for performing a special move * criticalHitSound **Actor** * CameraShake : Create a camera shake, 0.5s. For heavy attacks. Only seen by the player doing the animation. Effect files can also do this. * LongCameraShake : Create a long camera shake, 9 seconds. * DisplaceGrass : Create a CreatePointDisturbance that displaces grass/vegetation and water. **Death** * deathSound* (1-3) : Play death sound during death anim * bodyFallSound : When using a death animation instead of ragdoll, the moment when it hits the ground is specified with this. * spawnDeathActor : Define custom frame for creatures that spawn another creature on death * dissolve : For creatures that die and disappear in a dissolve start it with this trigger. Otherwise it starts at the moment of death. **Other** * DeathManager::AnimationCallback Delegates forward to all of it’s DeathHandlers. * End Finish() on the deathHandler * spawnDeathActor SpawnsActor() on the handler
