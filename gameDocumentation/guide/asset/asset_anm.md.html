(#) Formats - ANM The animation (.anm) files contains a animation for animated meshes. The file It contains the animation data for the bones. Each bone has the keys for all the frames. At the end there can be a AIF file. # TqKey ~~~~~~~~~~~~~~~~~~ TqKey TqVec3 pos Quat rot TqVec3 scale // if version >= 2 Quat scaleRot // if version >= 2 ~~~~~~~~~~~~~~~~~~ # TqBone ~~~~~~~~~~~~~~~~~~ TqBone uint8_t name[32] Key keys[numKeys] ~~~~~~~~~~~~~~~~~~ # TqAnmHeader ~~~~~~~~~~~~~~~~~~ TqAnmHeader uint32_t numBones // Number of bones in this file. uint32_t numKeys // Number of keys in each bone. uint32_t fps ~~~~~~~~~~~~~~~~~~ # Aif Data If after reading the content of the files based on the header and there are things left in the file the rest of it is the [aif or Animation Information File](../viewer_aif.md.html) . # Anm File Layout If the file does not start with ANM the file is version 1. ~~~~~~~~~~~~~~~~~~ uint8_t tag[3] // ANM if version >= 2 uint8_t version // if version >= 2 HeaderAnm header TqBone bones[numBones] uint8_t aifData // if not at end of file there is AIF data. ~~~~~~~~~~~~~~~~~~
