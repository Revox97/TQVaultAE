(#) Formats - SSH The .ssh files contain the directx graphic shaders the game use. * Most contain two set of shaders, one for DirectX9 and one for DirectX11. This is the API. * Each API can then have different shaders for different generations of graphic cards. Mostly a DX9 thing. This is the generation. * Each generation is described in four blocks of information. * blockParameters * blockConstants * blockStyles * blockMetadata # BlockHeader Each block start with the same header. It gives the type of block and the length of it. ~~~~~~~~~~~~~~~~~~ uint32_t blockType; uint32_t length; ~~~~~~~~~~~~~~~~~~ # Block ## 0 = blockParameters ~~~~~~~~~~~~~~~~~~ uint32_t numParameters Parameter parameters[numParameters] TqString name uint32_t type uint32_t numElements Bool editable Bool bound Value value ~~~~~~~~~~~~~~~~~~ ## 1 = blockConstants ~~~~~~~~~~~~~~~~~~ uint32_t numConstants ~~~~~~~~~~~~~~~~~~ ## 2 = blockStyles ~~~~~~~~~~~~~~~~~~ uint32_t numStyles Styles styles[numStyles] TqString name int32_t sortOrder uint32_t numPasses Pass Passes Uint numStateBindings StateBinding StateBindings[numStateBindings] int32_t state uint32_t stateIndex Bool constant UInt32 valueIndex ~~~~~~~~~~~~~~~~~~ ## 3 = blockMetadata ~~~~~~~~~~~~~~~~~~ uint32_t flags // Bitflags // bit 0 set: FOLIAGE // bit 1 set: SKINNED ~~~~~~~~~~~~~~~~~~ # NameList ~~~~~~~~~~~~~~~~~~ TqString name // name of generation uint32_t length // Length of section Block blocks[] // Until end of nameList ~~~~~~~~~~~~~~~~~~ # API ~~~~~~~~~~~~~~~~~~ uint8_t apiIdentifier // 0 for RenderApi_Direct3D and 1 for RenderApi_Direct3D11. uint32_t length // Number of bytes this API block is. Namelist generations[] // Until end of API ~~~~~~~~~~~~~~~~~~ # SSH File Layout ~~~~~~~~~~~~~~~~~~ uint8_t tag[3] // The characters SSH. uint8_t version // Always the number 6.
