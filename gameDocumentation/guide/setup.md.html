# Where are the mod tools The mod tools for Titan Quest is in the folder where your game is installed. ## Steam 1. Right click on Titan Quest Anniversity in your steam library and select properties. 2. Switch to the Local Files tab in the properties window. 3. Click browse local files to open the game folder in windows explorer. ## GOG 1: If you use GOG galaxy right click on the game in your library and then select Manage installation/Show folder. # What tools is there There are a few programs used to make the mods for Titan Quest. To make it more easy to use it is best to create shortcuts to them on your desktop. 1. Right click on a ArtManager and select create shortcut in the windows menu. 2. Drag and drop the new file ArtManager - Shortcut to your desktop. 3. Do the same for the other tools you will need. * Editor * QuestEditor * Viewer # Setting Up the Tools The prepare the tools you will need to perform the following steps in the ArtManager. 1. Start the Art Manager. 2. You will prompted to choose your working directories. The default values are good – just click ‘OK’. 3. The first time the ArtManager is setup it will install the templates. They describe for the mod tools how the objects in Titan Quest is made. You can reinstall the templates using the Help/Install Templates menu. It can be required if you work on a mod when there is a new update released of Titan Quest. 4. If you plan to do the Tutorials in this mod guide go to the Help menu and select ‘Install Tutorials’. This will copy the tutorial files that you should use while reading this guide. 5. Everything should now be properly set up. ![Art manager options settings](guide_images/art_manager/artm_options.png) # The Options The options are saved in ocuments\My Games\Titan Quest - Immortal Throne\Tools.ini. The default values for the directories should work for most use cases. Here we describe them in more detail if you need to modify them. **Working Directory** - Documents\My Games\Titan Quest - Immortal Throne\Working\ This is the place where the source files for the mod you are working on are placed. An extra Custommaps folder are created in the selected working folder and the mods are then found in it. **Build Directory** - Documents\My Games\Titan Quest - Immortal Throne When you build a mod from the artmanager it will be put in a custommaps folder in the Build Directory. The defaults is where Titan Quest is looking for mods to load so you can test your mod. **Tools Directory** The path where all the tools for mods can be found. Defaults to the install directory of the game. **Additional Browse directories** Here you can enter multiple directories seperated by semicolon. Some tools, like the viewer, will load this paths. If you add the titan quest game directory you can browse the game models in the viewer. Add the path to your mod in the Build Directory to view it's models.
